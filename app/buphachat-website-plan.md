# แผนเว็บไซต์โปรโมทร้าน (อ้างอิง Premium Fruit)

อัปเดต: 2026-11-02

## TL;DR

ยืมโครงเนื้อหาจาก premium-fruit.co.th แต่ตัดให้เบาลงครึ่งหนึ่งเพื่อให้เป็นมินิมอล ปิดการขายผ่าน LINE แทนตะกร้าสินค้า

ข้อมูลร้านจากเพจ Facebook (buphachat.chon) ยังยืนยันไม่ได้ เพราะเปิดอ่านอัตโนมัติไม่ได้ และค้นเว็บแล้วยังไม่เจอ

## แกะเว็บต้นแบบ

[Premium Fruit](https://premium-fruit.co.th/) วาง 10 section ในหน้าแรก และปิดการขายผ่าน LINE

**เมนูหลัก:** หน้าแรก / สินค้า (mega menu) / เกี่ยวกับเรา / รีวิวลูกค้า / บทความ / ติดต่อเรา

**ลำดับ section หน้าแรก:**

1. Hero ชูความน่าเชื่อถือ + ปุ่มสั่งซื้อไป LINE
2. แกลเลอรีรูปคนดังและลูกค้า
3. หมวดสินค้าตามโอกาส (เทศกาล เยี่ยมไข้ วันเกิด)
4. สินค้าขายดีพร้อมราคา
5. ภาพความประทับใจและรีวิว
6. FAQ (จัดส่ง สั่งล่วงหน้า เปลี่ยนสินค้า ใบกำกับภาษี เวลาเปิด)
7. วิธีสั่งซื้อเป็นขั้นตอนภาพ
8. บทความ (SEO)
9. จุดเด่นวัตถุดิบและเรื่องราวแบรนด์
10. Footer: โทร LINE อีเมล Facebook ที่อยู่

| | รายการ |
| --- | --- |
| ควรยืม | ปิดการขายผ่าน LINE, จัดหมวดตามโอกาส, FAQ + วิธีสั่งซื้อ, รีวิวรูปจริง |
| ไม่ควรยืม | mega menu 20+ ลิงก์, section ซ้ำ, ปุ่มเป็นไฟล์ภาพ, หน้าแน่นเกินมินิมอล |

## โครงเว็บที่ปรับแล้ว

หน้าแรกเหลือ 7 section จากเดิม 10 และหน้าเรื่องราวแบรนด์คือจุดขาย

| หน้า | Section | หมายเหตุ |
| --- | --- | --- |
| หน้าแรก | Hero → เรื่องย่อ → หมวดตามโอกาส (3–6 ใบ) → สินค้าเด่น 4 ชิ้น → รีวิวแถวเดียว → วิธีสั่ง 3 ขั้น → CTA LINE | 7 section |
| เรื่องราวของเรา | จุดเริ่มต้น → วิธีคัดสรร/ทำ → ทีม/หน้าร้าน → ความเชื่อ | จุดเด่นที่ต้นแบบทำน้อย |
| สินค้า | ตัวกรองตามโอกาส → grid | ไม่ใช้ mega menu |
| รายละเอียดสินค้า | gallery, เรื่องเล่า, ราคาเริ่มต้น (ทางเลือก), ปุ่มสอบถาม LINE | ส่งชื่อสินค้าไปใน LINE |
| รีวิว | masonry รูปลูกค้า | |
| FAQ + วิธีสั่งซื้อ | accordion | รวมหน้าเดียวได้ |
| ติดต่อ | แผนที่, เวลาเปิด, ช่องทาง | |
| บทความ | — | เฟส 2 เมื่อมีคนเขียนต่อเนื่อง |

## สเปกรายหน้า

แต่ละหน้ามีเป้าหมายเดียวและ CTA หลักเดียวคือ "สอบถามทาง LINE" ข้อความตัวอย่างเป็นข้อความชั่วคราว ต้องแทนด้วยข้อมูลจริงของร้าน

### 1. หน้าแรก `/`

**เป้าหมาย:** ภายใน 5 วินาที คนต้องรู้ว่าร้านขายอะไร ต่างจากที่อื่นยังไง และทักร้านได้ทางไหน

| ลำดับ | Section | ข้อมูลที่แสดง | ภาพ/สื่อ | การจัดวาง |
| --- | --- | --- | --- | --- |
| 1 | Header | โลโก้, เมนู 5 ลิงก์ (สินค้า เรื่องราว รีวิว คำถาม ติดต่อ), ปุ่ม LINE | โลโก้ SVG | sticky โปร่งใส → พื้นทึบเมื่อเลื่อน; มือถือใช้ hamburger |
| 2 | Hero | หัวข้อ 1 บรรทัด (≤ 12 คำ), ข้อความรอง 1 บรรทัด, ปุ่ม "ดูสินค้า" + "ทัก LINE" | รูปสินค้าเต็มจอ 1 รูป (16:9 desktop, 4:5 มือถือ) | ข้อความชิดซ้ายล่าง สูง 90vh |
| 3 | เรื่องย่อแบรนด์ | 2–3 ประโยค: เริ่มเมื่อไหร่ ทำเพื่อใคร ใส่ใจเรื่องอะไร + ลิงก์ "อ่านเรื่องของเรา" | รูปเบื้องหลัง 1 รูป | 2 คอลัมน์ รูป:ข้อความ |
| 4 | ช้อปตามโอกาส | การ์ด 3–6 ใบ: ชื่อโอกาส + คำโปรย 1 บรรทัด | รูปละ 1 ใบ อัตราส่วน 4:5 | grid 3 คอลัมน์ / มือถือ scroll แนวนอน |
| 5 | สินค้าแนะนำ | 4 ชิ้น: รูป, ชื่อ, ราคาเริ่มต้น (ถ้ามี) | รูปพื้นหลังสีเดียวกัน | grid 4 / มือถือ 2 คอลัมน์ |
| 6 | จุดเด่น 3 ข้อ | หัวข้อสั้น + คำอธิบาย 1 ประโยค ต่อข้อ | ไอคอนเส้นบาง | 3 คอลัมน์ พื้นที่ว่างเยอะ |
| 7 | รีวิว | 3–6 รีวิว: ข้อความสั้น, ชื่อย่อลูกค้า, โอกาส | รูปลูกค้าได้รับสินค้า (ขออนุญาตก่อน) | carousel แถวเดียว |
| 8 | วิธีสั่ง 3 ขั้น | 1 เลือกแบบ → 2 ทัก LINE แจ้งวัน/ที่อยู่ → 3 ชำระและรอรับ | ตัวเลขใหญ่แทนรูป | แนวนอน / มือถือแนวตั้ง |
| 9 | CTA ปิดท้าย | ประโยคชวนทัก + ปุ่ม LINE ใหญ่ | พื้นสี accent | เต็มความกว้าง |
| 10 | Footer | ที่อยู่, โทร, เวลาเปิด, LINE, Facebook, ลิงก์ทุกหน้า, ©ปี | — | 3–4 คอลัมน์ |

### 2. เรื่องราวของเรา `/story`

**เป้าหมาย:** สร้างความเชื่อใจและความผูกพัน หน้านี้แทนการขายตรง

| ลำดับ | Section | ข้อมูลที่แสดง | ภาพ/สื่อ |
| --- | --- | --- | --- |
| 1 | หัวเรื่อง | ประโยคตัวตนแบรนด์ 1 ประโยค | รูปหน้าร้านหรือเจ้าของ แนวกว้าง |
| 2 | จุดเริ่มต้น | ปีที่เริ่ม, ใครเริ่ม, เหตุผลที่เริ่ม (1 ย่อหน้า) | รูปเก่า/รูปจริงช่วงแรก |
| 3 | วิธีทำ/คัดสรร | 3–4 ขั้นตอน แต่ละขั้น 1–2 ประโยค | รูปขั้นละ 1 รูป สลับซ้าย-ขวา |
| 4 | คนเบื้องหลัง | ชื่อเล่น บทบาท 1 บรรทัด ต่อคน | portrait สไตล์เดียวกัน |
| 5 | สิ่งที่เราเชื่อ | 3 ค่านิยม ข้อละ 1 ประโยค | ไม่ใช้รูป เน้นตัวอักษรใหญ่ |
| 6 | ตัวเลข (ถ้ามีจริง) | เช่น ปีที่ทำ, จำนวนออเดอร์ — ใส่เฉพาะตัวเลขที่ตรวจสอบได้ | — |
| 7 | CTA | "ดูสินค้า" + "ทัก LINE" | — |

**ข้อมูลที่ต้องขอจากร้าน:** ปีที่เริ่ม, เรื่องจุดเริ่มต้น, ขั้นตอนทำงานจริง, รูปเบื้องหลัง 8–12 รูป

### 3. สินค้าทั้งหมด `/products`

**เป้าหมาย:** ให้คนหาแบบที่เหมาะกับโอกาสของตัวเองได้เร็ว

| ส่วน | ข้อมูล/พฤติกรรม |
| --- | --- |
| หัวหน้า | ชื่อหน้า + 1 ประโยคอธิบาย |
| ตัวกรอง | chip ตามโอกาส (ทั้งหมด, วันเกิด, แสดงความยินดี, เยี่ยมไข้ ฯลฯ) เลือกได้ทีละ 1; เก็บค่าใน URL `?occasion=birthday` เพื่อแชร์ลิงก์ได้ |
| การ์ดสินค้า | รูป 4:5, ชื่อ, ราคาเริ่มต้นหรือ "สอบถามราคา", ป้าย "ใหม่"/"ตามฤดูกาล" (ทางเลือก); hover แสดงรูปที่ 2 |
| การเรียง | ตาม `order` ที่ร้านกำหนดใน CMS ไม่ต้องมีปุ่มเรียงราคา |
| สถานะว่าง | "ยังไม่มีสินค้าในหมวดนี้" + ปุ่มทัก LINE ขอสั่งทำพิเศษ |
| Grid | desktop 3–4 คอลัมน์, tablet 3, มือถือ 2 |
| ใต้ grid | แถบ "อยากได้แบบเฉพาะ? ทักมาออกแบบด้วยกัน" + ปุ่ม LINE |

### 4. รายละเอียดสินค้า `/products/[slug]`

**เป้าหมาย:** ให้ข้อมูลพอตัดสินใจ แล้วกดทัก LINE พร้อมชื่อสินค้า

| ส่วน | ข้อมูลที่แสดง | หมายเหตุ |
| --- | --- | --- |
| Breadcrumb | สินค้า / หมวด / ชื่อ | ช่วย SEO |
| Gallery | 3–6 รูป: หน้าตรง, มุมเฉียง, รายละเอียดใกล้, ขณะใช้งานจริง | ซ้าย 60% desktop; มือถือ swipe + จุดบอกตำแหน่ง; แตะเพื่อขยาย |
| ข้อมูลหลัก | ชื่อ, หมวด/โอกาส, ราคาเริ่มต้น (ทางเลือก), คำโปรย 1–2 ประโยค | ขวา 40% sticky |
| CTA | ปุ่ม "สอบถามทาง LINE" เติมข้อความ "สนใจ {ชื่อ} ({รหัส})" + ปุ่มรองโทร | ปุ่มลอยติดล่างจอบนมือถือ |
| เรื่องเล่าสินค้า | ทำไมมีชิ้นนี้ เหมาะกับใคร โอกาสไหน (1–2 ย่อหน้า) | |
| สเปก | ตาราง: ขนาด, ส่วนประกอบ/วัสดุ, ปรับแต่งได้อะไร, สั่งล่วงหน้ากี่วัน, วิธีเก็บรักษา | ใส่เฉพาะช่องที่มีข้อมูล |
| สั่งยังไง | ย่อ 3 ขั้นจากหน้าแรก | ลิงก์ไป FAQ |
| สินค้าที่คล้ายกัน | 4 ชิ้นในโอกาสเดียวกัน | |
| SEO | `generateMetadata` ชื่อ+คำโปรย, OG image = รูปแรก, JSON-LD `Product` | |

### 5. รีวิว `/reviews`

**เป้าหมาย:** หลักฐานว่ามีลูกค้าจริงและพอใจจริง

- หัวหน้า: ชื่อหน้า + จำนวนรีวิว (เฉพาะตัวเลขจริง)
- ตัวกรองตามโอกาส (ใช้ชุดเดียวกับหน้าสินค้า)
- การ์ดรีวิว: รูป, ข้อความ ≤ 3 บรรทัด, ชื่อย่อ, โอกาส, ลิงก์ไปสินค้าที่สั่ง
- จัดแบบ masonry 3 คอลัมน์ / มือถือ 1 คอลัมน์; โหลดเพิ่มทีละ 12
- ห้ามแต่งรีวิวเอง ใช้เฉพาะรีวิวที่ลูกค้าให้มาและยินยอมให้เผยแพร่

### 6. คำถามที่พบบ่อย + วิธีสั่งซื้อ `/faq`

**เป้าหมาย:** ตอบคำถามซ้ำก่อนลูกค้าทักมา ลดภาระแอดมิน

| กลุ่ม | ตัวอย่างคำถาม |
| --- | --- |
| การสั่ง | สั่งล่วงหน้ากี่วัน, สั่งด่วนวันนี้ได้ไหม, ปรับแต่งได้ไหม |
| การจัดส่ง | ส่งพื้นที่ไหน, ค่าส่งคิดยังไง, ส่งเช้าสุดกี่โมง, ส่งต่างจังหวัดได้ไหม |
| การชำระเงิน | ช่องทางชำระ, มัดจำไหม, ออกใบกำกับภาษีได้ไหม |
| คุณภาพ | รับประกันอะไร, ถ้าสินค้ามีปัญหาทำยังไง |
| หน้าร้าน | อยู่ที่ไหน, เปิดกี่โมง, หยุดวันไหน |

- แสดงเป็น accordion แยกกลุ่ม; ส่วนบนเป็น "วิธีสั่ง 3 ขั้น" แบบมีภาพ
- ท้ายหน้า: "ไม่เจอคำตอบ? ทัก LINE"
- ใส่ JSON-LD `FAQPage`

### 7. ติดต่อเรา `/contact`

**เป้าหมาย:** ทักหรือมาที่ร้านได้ทันที

| ส่วน | ข้อมูล |
| --- | --- |
| ช่องทาง | การ์ด LINE (ปุ่ม + QR), โทร (`tel:`), Facebook, อีเมล (ถ้ามี) |
| หน้าร้าน | ที่อยู่เต็ม, เวลาเปิด-ปิดแต่ละวัน, วันหยุด |
| แผนที่ | Google Maps embed แบบ lazy-load + ปุ่ม "นำทาง" |
| ฟอร์ม (ทางเลือก) | ชื่อ, เบอร์/LINE ID, โอกาส, วันที่ต้องการ, ข้อความ → ส่งเข้าอีเมลหรือ LINE ร้าน |
| PDPA | ข้อความสั้นใต้ฟอร์ม: เก็บข้อมูลเพื่อติดต่อกลับเท่านั้น + ลิงก์นโยบายความเป็นส่วนตัว |

### 8. หน้าระบบที่ต้องมี

- `/privacy` นโยบายความเป็นส่วนตัว (จำเป็นถ้ามีฟอร์มหรือ analytics)

- `sitemap.xml`, `robots.txt`, OG image ทุกหน้า

## ผลต่อ Tech Stack

ใช้ Next.js + TSX + Tailwind + Sanity ตามเดิม แค่เพิ่ม schema และคอมโพเนนต์เล็กน้อย

- **Content model เพิ่ม:** `occasion`, `review`, `faq`, `orderStep`
- **`LineCTA.tsx`:** สร้างลิงก์ LINE พร้อมข้อความ "สนใจ {ชื่อสินค้า}"
- **SEO:** JSON-LD `LocalBusiness`, `Product` (ไม่มี `offers`), `FAQPage`
- **ไม่ต้องทำ:** ค้นหา, ตะกร้า, ชำระเงิน
